طريقة تشغيل واستخدام صفحة الهبوط (Landing Page) وتحميل التطبيق:

1. قم بفتح تيرمنال المشروع وبناء نسخة الـ APK النهائية عن طريق تشغيل الأمر التالي:
   flutter build apk --release

2. بعد انتهاء عملية البناء، سيتم توليد ملف الـ APK في المسار التالي:
   build/app/outputs/flutter-apk/app-release.apk

3. قم بنسخ هذا الملف (app-release.apk) وضعه داخل المجلد الحالي (landing_page) بجانب ملف (index.html).

4. الآن، عند رفع المجلد الحالي (landing_page) على أي خدمة استضافة مجانية (مثل Vercel أو Netlify أو Firebase hosting):
   - سيعمل رابط الموقع الخاص بك كصفحة هبوط احترافية لعرض مشروع التخرج.
   - عند قيام أي شخص بالضغط على زر "Download APK"، سيتم تحميل التطبيق مباشرة على هاتفه الأندرويد وتثبيته فوراً.

*ملاحظة:* تم تصميم وتطوير هذه الصفحة محلياً بالكامل ولم يتم رفعها على مستودع GitHub بناءً على رغبتك.
